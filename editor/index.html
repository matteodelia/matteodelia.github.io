Contenuti di matteodelia.com

Per modificare il sito serve una chiave GitHub valida solo per il repository del sito. Si inserisce una volta per dispositivo.

Come creo la chiave?
  1. Apri github.com → Fine-grained token.
  2. Nome: Contenuti sito. Scadenza: quella che preferisci.
  3. Repository access: Only select repositories → matteodelia/matteodelia.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Genera la chiave, copiala e incollala qui sopra.
